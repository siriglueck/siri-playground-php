Welcome to **siri-playground-php** – a collection of PHP projects and exercises from various learning sources including books, online courses, and tutorials.

## 🎯 Purpose

This repository serves as a personal archive of PHP coding projects, exercises, and implementations completed while learning from various educational resources. Each project includes source code, notes, and documentation to facilitate future reference and review.

## 📖 Sources

### Books
Projects and exercises from technical books, organized by book title and chapter.

### Udemy Courses
Course projects organized by course name and section, including lecture notes and implementations.

### Internet Tutorials
Miscellaneous projects from blogs, documentation, YouTube tutorials, and other online resources.

## 🛠️ Technologies

This repository contains PHP projects using various web development technologies:

- [X] **PHP (7.x / 8.x)** (Core language features)
- [X] **MySQL / MariaDB** (Database management)
- [X] **PDO / MySQLi** (Database connections)
- [ ] **Sessions & Cookies** (State management)
- [X] **Forms & Validation** (User input handling)
- [X] **File Uploads** (File handling)
- [ ] **OOP PHP** (Object-oriented programming)
- [X] **MVC Pattern** (Design patterns)
- [ ] **Laravel / Symfony** (PHP frameworks)
- [ ] **Composer** (Dependency management)
- [ ] **RESTful APIs** (API development)
- [ ] **Authentication** (Login systems, JWT)

- Projects may vary in complexity from beginner exercises to advanced implementations
